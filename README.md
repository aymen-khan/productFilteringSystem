🛍️ Product Filtering System

A responsive product filtering web application built using HTML, CSS, and JavaScript.

 🚀 Features

🔍 Search products by name
📂 Filter products by category
💰 Sort products by price
 📱 Fully responsive design
⚡ Fast and interactive user interface
 🖼️ Product images loaded dynamically
 📄 Product data stored in JSON

 🛠️ Technologies Used

HTML5
 CSS3
JavaScript (ES6)
 JSON

 📁 Project Structure

productFilteringSystem/
│
├── images/
├── index.html
├── style.css
├── script.js
├── products.json
└── README.md

 ▶️ How to Run

1. Download or clone the repository.
2. Open index.html in your browser.
3. Browse, search, filter, and sort products.
